# Aitane Partner Program

Aitane販売・導入パートナー向けの公開提案資料です。

**公開URL:** https://aitane.github.io/aitane-partner-program/

- ログイン不要の静的HTML。全13章。
- スクロールに合わせた図の表示、章移動、資金推移の切り替えに対応。
- 右下のリンクからPDFをダウンロード可能。JavaScriptを無効にしても本文とPDFリンクを利用できます。
- PC・スマートフォンに対応。OSの「視差効果を減らす」設定を尊重します。
- 認証、アクセス解析、Cookie、外部API接続は使用していません。

## 更新・公開

GitHub Pagesは `main` ブランチのルートを公開します。変更をpushすると自動更新されます。
本文を修正した場合はPDFも再生成し、同じ変更でコミットしてください。

ローカル確認（Python 3）:

```sh
python -m http.server 8080 --bind 127.0.0.1
```

`http://127.0.0.1:8080/` を開きます。サーバーやデータベースの運用は不要です。

## 商業条件

- A方式：通常はAitaneが利用料を回収し、顧客入金月の翌月末にパートナーへ10%報酬。
- B方式：Aitane認定パートナー登録済み、かつ補助金利用案件のみ。顧客から契約期間分を一括受領し、Aitaneへ毎月払い。
- B方式の10%差引・90%精算は標準案。締日等は取扱契約で合意。
- 支援料はパートナーが設定し、顧客と直接契約・回収。
- Aitaneの認定と補助金制度上の登録・審査は別。

2026年10月4日時点の提案内容です。資料の公開は認定・登録・採択の確約ではありません。

## 顧客の補助金試算

5ID × 月額5,000円 × 24か月 = 税抜60万円を全額対象とし、通常枠で1/2補助を受ける場合の例です。税込66万円を先払いし、後日補助金30万円を受領、差引支出は36万円（消費税の仕入税額控除等を考慮しない）です。支援料・AI/API利用料は含みません。制度上の登録・審査・交付決定等が必要です。

出典：[通常枠](https://it-shien.smrj.go.jp/applicant/subsidy/normal/)、[公募要領](https://it-shien.smrj.go.jp/pdf/it2026_koubo_tsujyo.pdf)。
